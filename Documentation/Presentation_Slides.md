# FOOD ORDERING WEB APPLICATION
## Presentation Slides Outline

### Slide 1: Title Slide
- Title: Food Ordering Web Application
- Subtitle: A digital solution for local food businesses in Zimbabwe
- Presented by: [Student Name]
- Department: School of Engineering & ICT
- Institution: Arrupe Jesuit University

### Slide 2: Problem Statement
- Many businesses still use phone calls and messaging apps for orders.
- Orders are often delayed or mismanaged.
- Lack of centralized coordination between customers, restaurants, and delivery persons.
- Existing international systems are too expensive for local SMEs.

### Slide 3: Aim and Objectives
- Aim: Design and develop a web-based food ordering system.
- Objectives:
  - Centralized system architecture
  - Menu browsing and order placement
  - Restaurant order management
  - Delivery tracking
  - Simulated end-to-end order process

### Slide 4: Project Significance
- Improves service efficiency
- Reduces communication errors
- Saves time for restaurant staff and delivery teams
- Helps local businesses go digital at low cost
- Makes it easier to manage records and track performance

### Slide 5: System Architecture
- Presentation Layer: Frontend interfaces
- Application Layer: Backend logic and API
- Data Layer: SQLite database
- Flow: Customer -> Order -> Restaurant -> Delivery -> Status update

### Slide 6: User Interfaces
- Customer interface
  - View menu
  - Add products to cart
  - Fill delivery details
  - Submit order
- Restaurant dashboard
  - View incoming orders
  - Update status
- Delivery dashboard
  - Track order progress
  - Mark as delivered

### Slide 7: Technologies Used
- HTML, CSS, JavaScript
- Node.js
- Express.js
- SQLite Database
- Visual Studio Code

### Slide 8: Implementation Highlights
- Responsive web pages
- Order validation and database storage
- Live order status updates
- Admin summary dashboard
- Simple login and role-based access

### Slide 9: Demonstration Flow
- Customer selects item
- Customer submits order
- Restaurant receives order
- Restaurant updates status
- Delivery staff updates final status
- System stores order data and tracks progress

### Slide 10: Results and Evaluation
- Functional prototype was successfully implemented
- Main objectives were achieved
- System demonstrates a complete ordering workflow
- Strong foundation for future expansion

### Slide 11: Challenges and Solutions
- Limited runtime environment setup
- Need for database and backend coordination
- Resolved using SQLite and structured API design
- Simplified architecture to suit project timeline

### Slide 12: Conclusion
- The project provides a practical solution to local food ordering challenges.
- It is affordable, usable, and suitable for small businesses in Zimbabwe.
- It demonstrates how digital systems can improve efficiency and customer service.

### Slide 13: Future Work
- Add online payment integration
- Add mobile app version
- Add SMS/email notifications
- Add restaurant menu management
- Expand to multi-restaurant operations

- Thank you
