How to set up the shortcut (about 3 minutes)
  1. Get your key: tap Set up iPhone sync above and keep this page open.
  2. On your iPhone open the Shortcuts app → tap + → name it Sync to THE KITCHEN.
  3. Add Find Health Samples: Type Steps, add the filter Start Date is Today.
  4. Add Calculate Statistics: Sum of Health Samples.
  5. Add another Find Health Samples: Type Active Energy, Start Date is Today, then another Calculate Statistics → Sum.
  6. Add Get Contents of URL: paste the sync address. Tap Show More → Method POST → Request Body JSON and add three fields:
    • key (Text) = your personal key
    • steps (Number) = the first Statistics result
    • kcal (Number) = the second Statistics result
  7. Optional: add Show Notification with the text Synced to THE KITCHEN ✅.
  8. Tap ▶ to run it once and allow Health access and the connection to the site. Your steps appear here.
  9. Make it automatic: Shortcuts → Automation → + → Time of Day → 21:00, Daily → Run Immediately → choose Sync to THE KITCHEN.

Steps above an everyday 3,000 count as active minutes (about 100 steps a minute of brisk walking), so a long walk fills your Move ring. If you also log the same walk, only the bigger number counts. Android phones: connect Fitbit or log activity above.
